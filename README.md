# CRAFT TEAM — набор в состав Minecraft-сервера

Анкета-тест как Telegram Mini App: игрок выбирает вакансию, проходит тест,
результат мгновенно приходит администратору в ЛС от бота и сохраняется в
реестр заявок.

## Стек

- **Язык:** Python **3.12** (см. `bothost.json`, минимум 3.11)
- **Порт:** `3594` — берётся из переменной `PORT`, должен совпадать с полем
  «Порт» в панели Bothost
- **Веб-сервер + бот в одном процессе:** `aiohttp` (статика, `/health`,
  `/api/env.js`) + `aiogram 3` (long polling)
- **Фронт:** статические `index.html` / `admin.html` / `view.html` (Tailwind CDN)

## Файлы

| Файл            | Назначение                                                    |
|-----------------|---------------------------------------------------------------|
| `main.py`       | Точка входа: сайт + бот в одном процессе (см. `bothost.json`) |
| `bot.py`        | Бот: приветствие в ЛС, кнопка Mini App, кнопка меню чата      |
| `index.html`    | Mini App: выбор вакансии и прохождение теста                  |
| `admin.html`    | Панель админа: редактор вакансий/вопросов, данные             |
| `view.html`     | Реестр заявок: просмотр ответов, принять/отклонить            |
| `bothost.json`  | Конфиг Bothost: `main.py`, Python 3.12                        |
| `requirements.txt` / `.env.example` / `Procfile` | Деплой                       |

## Локальный запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # впиши BOT_TOKEN, ADMIN_ID, WEBAPP_URL
python main.py         # сайт: http://localhost:3594 + бот
```

Отдельно только бота можно поднять так: `python bot.py`.

## Деплой на Bothost (bothost.ru)

1. **Создать бота** в панели Bothost → платформа **Telegram** → загрузить
   репозиторий/ZIP. В корне уже лежат `bothost.json`, `requirements.txt`,
   `main.py` — хостинг соберёт образ сам, свой Dockerfile не нужен.
2. **Переменные окружения** в панели (.env на хостинге не читается!):

   | Переменная   | Значение                                                        |
   |--------------|------------------------------------------------------------------|
   | `BOT_TOKEN`  | токен от @BotFather                                              |
   | `ADMIN_ID`   | твой числовой Telegram ID (@userinfobot)                         |
   | `PORT`       | `3594` — **должно совпадать с полем «Порт»** в панели            |
   | `WEBAPP_URL` | заполнить после шага 3                                           |

3. Включи **«Использовать домен»** → Bothost выдаст
   `https://<id>.bothost.tech` (или подключи свой домен в той же панели).
   Этот адрес впиши в `WEBAPP_URL` — именно его бот подставит в кнопку
   «Открыть анкету».
4. **Пересобрать** после смены домена или порта — иначе прокси и контейнер
   разъедутся (502/504).
5. Проверка по порядку:
   - `https://<твой-домен>/health` → `{"ok": true}`
   - `https://<твой-домен>/` — открывается список вакансий
   - в Telegram: `/start` боту → приветствие + кнопка «Открыть анкету»
     (кнопку меню чата бот ставит сам при старте, BotFather трогать не нужно)

Обновление кода: `git push` → в панели **Пересобрать**.

## Как страницы получают конфиг

При деплое на Bothost страницы читают `ADMIN_ID`/`BOT_TOKEN` с сервера через
`/api/env.js` (приоритет №1). Фолбэк — localStorage домена: те же значения
можно один раз ввести в `admin.html` → вкладка «Бот и данные».

> Замечание по безопасности: токен, отдаваемый через `/api/env.js`, виден в
> исходниках страницы любому, кто откроет сайт. Для публичного продакшена
> имеет смысл перенести `sendMessage` на серверный эндпоинт.
